# Complyon

Complyon is a modern AI compliance dashboard prototype built with React and Tailwind CSS.

It demonstrates the front-end experience for a Graph RAG compliance intelligence product that helps EU investment firms navigate complex, overlapping regulations with faster and clearer workflows.

## What This Project Includes

- Premium dashboard-style landing UI
- Responsive layout for desktop and tablet
- Reusable React components
- Tailwind utility-based styling
- Lucide React icons

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Getting Started

### 1) Install dependencies

```bash
npm install
```

### 2) Run development server

```bash
npm run dev
```

By default, the app runs at `http://localhost:5000` in this setup.

### 3) Build for production

```bash
npm run build
```

## Project Structure

```text
src/
  App.tsx        # Main dashboard page UI
  main.tsx       # React entry point
  index.css      # Tailwind imports + global styles
```

## Notes

- This repository currently focuses on the UI layer and product presentation.
- Backend Graph RAG ingestion, retrieval, and compliance logic are not yet implemented here.
